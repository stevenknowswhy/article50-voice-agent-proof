# Security policy

Do not report credentials, phone numbers, payment data, caller recordings, or personal lead information in a public issue.

This repository contains only a reference implementation. It does not operate a hosted service, retain caller data, or expose a live telephone number. Before deployment, use provider-managed secrets, least-privilege credentials, explicit retention controls, and a reviewed private lead sink.

For a non-sensitive implementation question, use the repository's issue template. For private business fit, email `article50-launch-agent@agentmail.to`; do not send credentials or source code.
